# Sandspiel 画布优先的 Figma/FigJam 材料实验台

## 目标

把 Sandspiel 的界面重新组织为画布优先的材料创作工作台。Figma/FigJam 提供工具栏、细描边、中性工作区和颜色分类语言；Sandspiel 保留自己的像素材料、模拟手感与视觉表现。界面不是 AAA 游戏宣传页，也不采用 Figma 营销页的大标题、CTA 或卡片陈列结构。

## 核心原则

1. 中央 300x300 模拟画布是唯一视觉核心，UI 只为选择材料、绘制和观察反应服务。
2. 中性色负责工作台骨架，pastel 色只表达材料家族，材料 swatch 始终使用 Sandspiel 原生 palette。
3. 信息按需出现。右侧 Inspector 默认收起，避免常驻面板压缩画布。
4. 所有改动停留在 UI 层，不改变材料行为、像素渲染、输入手感或存档兼容性。

## 视觉语言

### 工作区

- 使用暖灰白画布背景、低对比网格和细 hairline，建立 FigJam 式开放工作区。
- 画布周围保留充足留白，只用细描边和克制的暖色阴影承托，不使用厚重游戏 HUD 或装饰性动态背景。
- 继续使用仓库内的 `Mondwest` 和 `NeueBit` 字体：前者用于品牌与少量标题，后者用于工具、材料名称、状态和数值。

### 材料颜色

- 基础材料：淡蓝。
- 生命材料：薄荷绿。
- 能量材料：柔和珊瑚色。
- 特殊材料：薰衣草色。
- 风和通用操作使用中性或单一强调色，不再引入新的彩色体系。
- 家族色用于分组背景、标签或边缘提示；材料按钮中的 swatch 继续读取现有 `palette`，不重绘材料颜色。

### 控件状态

- 默认态平整、紧凑，依靠间距和 hairline 分层，避免每个元素都成为独立卡片。
- hover 使用轻微背景变化或 1px 位移；pressed 使用轻微缩放或下压。
- selected 使用深色描边、局部反转和清晰的 `aria-pressed` 状态。
- focus 必须有可见焦点环；减少动态效果偏好下关闭非必要过渡。

## 桌面布局

### 顶部工具栏

顶部工具栏保持紧凑，包含：

- Sandspiel 品牌和“材料实验台”说明；
- 运行中或已暂停状态；
- 暂停/继续、撤销、重置、上传和作品入口。

工具栏不出现营销文案、超大标题或主要 CTA。高频模拟操作排在前面，分享和浏览保持次级层级。

### 左侧材料栏

- 左侧材料栏常驻，但宽度保持克制。
- 材料按基础、生命、能量、特殊四个家族排列，每组使用对应 pastel 提示。
- 材料按钮显示原生颜色 swatch、中文名称和英文代码；密度接近设计工具的资产列表，而不是功能卡片墙。
- 风作为工具置于材料家族之前。
- 笔刷大小固定在材料栏底部，继续使用有效档位 `[1, 3, 7, 19, 39]`。

### 中央画布

- 画布占用顶部工具栏和左侧材料栏之外的最大可用区域。
- Inspector 收起时，画布按完整剩余工作区居中，而不是为隐藏面板预留固定宽度。
- 保持 `#sand-canvas` 与 `#fluid-canvas` 的层级、300x300 模拟、坐标换算和 `image-rendering: pixelated`。
- UI 装饰层不得拦截画布指针事件。

### 按需 Inspector

- Inspector 默认收起为右侧窄标签或图标按钮。
- 选择材料不会强制遮挡画布；用户可通过标签展开当前材料详情。
- 展开后显示材料名称、原生 swatch、简介、实验提示和反应关系。
- 关闭按钮和 `Escape` 都可收起；展开状态不改变当前材料选择。
- 面板使用覆盖式或占用有限宽度的方式出现，不永久改变画布尺寸。

## 移动端布局

- 顶部工具栏保持单行，高频操作优先，次要操作允许横向滚动。
- 画布使用顶部工具栏与底部托盘之间的最大空间，不被长说明文字挤压。
- 材料栏变为底部横向托盘，家族之间仍保留 pastel 分类。
- 笔刷档位位于托盘内的固定区域或首屏可见区域。
- Inspector 改为可关闭的底部抽屉，默认收起；抽屉展开时仍保留明确的画布返回路径。
- 目标视口至少覆盖 390x844，控件触摸目标不小于约 40px。

## 组件与状态边界

- `Index` 管理当前材料、笔刷大小、暂停状态和 Inspector 展开状态。
- `MATERIAL_GROUPS` 仅增加稳定家族 key 和展示语义，不改变 Species 映射或材料顺序。
- `MaterialInspector` 只消费当前材料详情和开合状态，不读写模拟数据。
- CSS 负责桌面、移动端布局以及家族色，不新增 UI 框架或运行时依赖。
- Inspector 即使缺少未知材料详情，也回退到清空工具说明，不能让主界面崩溃。

## 实现范围

- 修改 `js/styles.css`：设计 token、画布优先布局、家族色、折叠 Inspector、交互状态和响应式规则。
- 修改 `js/components/ui.js`：Inspector 开合状态、触发器、键盘关闭和必要的可访问属性。
- 必要时修改 `js/components/materials.js`：保持稳定家族 key；不改 Species ID 和材料顺序。
- 更新 `tests/figma-material-lab-ui.test.cjs`：覆盖 token、家族 hook、画布布局、折叠 Inspector 和像素渲染契约。

## 明确不做

- 不修改 Rust/WASM 材料规则、随机数、tick 顺序或内存协议。
- 不修改 Species 编号、shader、流体反馈、画布尺寸和绘制坐标。
- 不修改有效笔刷档位、撤销语义、存档格式、上传和历史作品加载协议。
- 不引入远程字体、图片素材、组件库或动画库。
- 不重写项目框架，不把实验台改造成营销落地页。

## 验收标准

1. 桌面首屏中，中央像素画布比任一工具面板更突出；Inspector 默认收起且不预留固定宽度。
2. 四个材料家族拥有稳定、低饱和的分类提示，原生材料 swatch 与像素画面颜色不变。
3. 暂停/继续、选择材料、五档笔刷、绘制、撤销和重置仍可正常使用。
4. Inspector 可通过明确控件展开和收起，并支持 `Escape`；开合不会改变材料选择或模拟状态。
5. 390x844 视口中画布、顶部操作和底部材料托盘均可用，无水平页面溢出或被遮挡的核心控件。
6. 静态 UI 契约测试、生产构建和浏览器桌面/移动端交互验证通过。
7. 最终 diff 不包含 Rust、shader、WASM 产物或存档协议改动。
