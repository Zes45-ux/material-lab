# Local UI fonts

These files are open-source substitutes for the Figma Sans and Figma Mono roles described in the design reference. They are not Figma proprietary fonts.

- `InterVariable.woff2`: Inter, SIL Open Font License 1.1. Source: https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2
- `JetBrainsMono-Regular.woff2`: JetBrains Mono, SIL Open Font License 1.1. Source: https://github.com/JetBrains/JetBrainsMono/blob/master/fonts/webfonts/JetBrainsMono-Regular.woff2

The full license text is available in the upstream repositories. Keep this attribution with the font files when redistributing the build.
